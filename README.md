# Tanzania Public Service Recruitment Analysis

**Author:** Data Analyst & Data Scientist

## Project Overview

This project analyzes 100 advertised post slots from two Tanzanian public institutions:

- Tanzania Forestry Services Agency (TFS)
- Mwalimu Nyerere Memorial Academy (MNMA)

The goal is to transform recruitment announcement data into meaningful insights using Microsoft Excel.

## Project Objectives

- Analyze recruitment distribution by institution.
- Identify job titles with the highest number of advertised slots.
- Examine recruitment distribution by job family.
- Analyze salary-scale categories.
- Examine minimum qualification requirements.
- Develop a professional recruitment dashboard.

## Tools Used

- Microsoft Excel Online
- Excel Tables
- PivotTables
- Charts and data visualization
- Data cleaning and quality checks

## Key Findings

- Total advertised post slots analyzed: **100**
- Institutions analyzed: **2**
- Unique job titles: **22**
- Unique job families: **20**
- TFS: **93 post slots (93%)**
- MNMA: **7 post slots (7%)**
- Forest Guard: **35 represented post slots**
- Beekeeping Assistant: **9 represented post slots**

## Methodology

1. Data organization and structuring.
2. Data quality checks.
3. Recruitment analysis using PivotTables.
4. KPI calculation and comparison.
5. Chart development.
6. Dashboard creation.
7. Analytical reporting.

## Project Deliverables

- Excel workbook containing the dataset and analysis.
- Recruitment dashboard.
- Analytical report.
- Data quality checks.

## Dataset Source

Public Service Recruitment Secretariat (PSRS), recruitment announcement dated 8 November 2025.

Reference: JA.9/259/01/C/7.

## Limitations

This project uses a selected sample of 100 advertised post slots from two institutions. It does not represent the complete national recruitment dataset. It also does not include applicant numbers, interview results, or recruitment outcomes.
